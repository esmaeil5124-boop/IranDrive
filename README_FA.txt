Iran Drive — پروژه اندرویدی آماده GitHub Actions

ساخت APK بدون نصب Android Studio روی رایانه شما:
1) این ZIP را استخراج کنید.
2) در GitHub یک repository جدید بسازید.
3) محتویات پوشه پروژه (همه فایل‌ها و پوشه‌ها، شامل .github) را در repository بارگذاری کنید.
4) تب Actions را باز کنید. Workflow با نام Build Iran Drive APK خودکار اجرا می‌شود (یا Run workflow).
5) پس از موفق شدن اجرا، در صفحه اجرای workflow پایین قسمت Artifacts فایل IranDrive-debug-apk را دانلود کنید.
6) ZIP artifact را باز کرده و app-debug.apk را به گوشی منتقل و نصب کنید. ممکن است Android اجازه نصب از منبع ناشناس را درخواست کند.

این پروژه APK debug می‌سازد و امضای انتشار (release) ندارد.
این فایل در محیط حاضر کامپایل/آزمایش نشده است.
